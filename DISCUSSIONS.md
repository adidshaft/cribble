# GitHub Discussions

Cribble uses GitHub Discussions for open-ended product ideas and roadmap
conversation. Issues should stay focused on bugs, agreed work, and actionable
tasks.

Use Discussions for:

- feature ideas;
- product direction questions;
- workflow proposals;
- integration/provider ideas;
- early design feedback;
- "would Cribble ever..." questions.

Use Issues for:

- reproducible bugs;
- broken builds or releases;
- documentation fixes;
- accepted feature work;
- security-safe diagnostics.

Before opening a feature pull request, please start with a Discussion or issue
and wait for maintainer agreement. This keeps contributor effort aligned with
Cribble's owner-led product direction.
