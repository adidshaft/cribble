# App

Application entry point and top-level wiring.

| File | Responsibility |
| --- | --- |
| `CribbleApp.swift` | `@main` SwiftUI `App` — scene setup, window configuration, lifecycle. |
| `CribbleCommands.swift` | Menu bar commands and keyboard shortcuts. |
| `AppIconManager.swift` | Per-folder icon selection and app icon handling. |
| `AppUpdater.swift` | In-app update checks for the direct-DMG distribution. |
