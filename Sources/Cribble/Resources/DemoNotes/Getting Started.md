# Getting Started

A two-minute tour of the everyday features. Try each one right here — nothing you do is permanent.

## Highlights

> **Try it**
> Select this phrase — *highlights are worth keeping* — and press **H**. It turns yellow and saves automatically. **Right-click** it to add a margin note, edit, or remove it.

Highlights anchor to the text, so they survive edits and reopening the note.

## Reading bookmarks

Press **B** anywhere to drop a bookmark at your scroll position. Reopen the note later and a **Resume** strip jumps you right back.

## Wiki links

Type `[[Note Name]]` to connect notes. Click to follow:

- [[Cribble AI]] — local-first chat with on-device and clearly labeled CLI choices.
- [[Feature Tour]] — zoom, trails, search, pathfinder.

Linking a note that doesn't exist yet — like [[A Note I Haven't Written]] —
still works: Cribble offers to create it for you, then shows the new note in the
same review sheet used by AI and daily-note proposals. Linking can come before
writing, and you still approve before anything is saved.

## Search (keyword + semantic)

Type in the toolbar search field. Cribble matches filenames *and* runs an on-device semantic index, so a **Related** section surfaces notes that mean the same thing. Try `keep my place while reading` — bookmarks and this note should surface. More in [[Feature Tour]].

## Focus, outline & folders

- **N** adds or edits the note on the highlight you are hovering. Away from a
  highlight, it still proposes a new `Untitled.md` note.
- **Command N** opens or proposes today's note in `Daily/YYYY-MM-DD.md`.
- **Space** toggles Focus Mode (hides the sidebar for distraction-free reading).
- **O** toggles the headings outline.
- **S** jumps to Search files, **C** opens AI chat, and **T** opens Tasks.
- **Right-click a folder** to **Pin** it to the top or **Choose Icon…** — both are sidebar-only; files on disk never move.
- **Right-click a note** to reveal it in Finder, copy its file path, copy Markdown, copy a normal Markdown link, or copy a `[[Wiki Link]]` for pasting into another note.

## Keyboard shortcuts

| Shortcut | Action |
| :--- | :--- |
| `H` | Highlight selected text |
| `B` | Drop or resume a reading bookmark |
| `R` | Toggle the Reading Trail panel |
| `Esc` | Exit highlight mode · close a zoom overlay |
| `←` / `→` | Back · Forward |
| `S` | Search files |
| `O` | Toggle outline |
| `I` | Project Intelligence |
| `C` | Open Cribble AI chat |
| `N` | Add note to hovered highlight / New note |
| `⌘ N` | Open today's note |
| `T` | Open Tasks |
| `E` | Open current file in your editor |
| `L` | AI Link Notes |
| `Space` | Toggle Focus Mode |
| `F` | Open current file in Finder |
| `⌘ M` | Copy current note as Markdown |
| `⌘ L` | Copy current note as a Markdown link |
| `⌘ W` | Copy current note as a wiki link |
| `⌘ I` | Import |
| `⌘ ,` | Settings |

## Mouse & trackpad

| Gesture | What it does |
| :--- | :--- |
| Right-click a highlight | Add, edit, or remove its note |
| Double-click a diagram / equation | Open the zoom overlay |
| Drag one note onto another | Open Pathfinder between them |
| Right-click a folder | Pin it, or choose an icon |
