# Cribble Brand and Trademark Policy

The Apache-2.0 license applies to Cribble's source code. It does not grant
rights to the Cribble name, app icon, logo, screenshots, release artwork, or
other brand assets.

The goal is simple: forks and derivative work are welcome, but users should not
be confused about what is an official Cribble release.

## Allowed uses

You may:

- say that your work is based on or compatible with Cribble;
- link to the official Cribble repository;
- keep required license and attribution notices;
- use screenshots in reviews, commentary, bug reports, or documentation;
- describe a fork as "a fork of Cribble" if it is clearly unofficial.

## Uses that need permission

Please ask before you:

- distribute a modified app using the name "Cribble";
- use the Cribble icon or logo as the primary branding for a fork;
- publish a website, package, or release that looks official;
- use Cribble branding in commercial material;
- imply maintainer endorsement.

Contact: `adidshaft@kyokasuigetsu.xyz`

## Official releases

Official Cribble releases are published by the maintainer through the official
GitHub releases, website, Sparkle feed, or App Store channels.
