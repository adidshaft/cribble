# appstore-assets

Artwork and screenshots for the Mac App Store listing and link previews.

| Path | What it is |
| --- | --- |
| `cribble-mac-store-artwork.png` | Primary App Store artwork. |
| `cribble-link-preview.png` | Link / social preview image. |
| `source/` | Source/working files for the artwork. |
| `screenshots/` , `product-screenshots/` | Rendered product screenshots. |
| `upload-screenshots/` | Final sized screenshots ready to upload to App Store Connect. |

Generate screenshots with
[`script/create_app_store_screenshots.py`](../script/create_app_store_screenshots.py).
Listing copy lives in [APP_STORE_METADATA.md](../APP_STORE_METADATA.md); the
launch checklist is [APP_STORE_LAUNCH.md](../APP_STORE_LAUNCH.md). These are
brand assets — see [TRADEMARK.md](../TRADEMARK.md).
